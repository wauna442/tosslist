# Claude instructions for Tosslist

Read [AGENTS.md](AGENTS.md) — it is the project guide for every AI tool.

The rules that outrank it are in [CONSTITUTION.md](CONSTITUTION.md) and
[GOVERNANCE.md](GOVERNANCE.md). The short version: work on a branch, open a
pull request, never push to or merge into `main` yourself, run the tests
first, and ask the maintainer before adding a store, a dependency, a new
kind of credential, or changing default behavior.
