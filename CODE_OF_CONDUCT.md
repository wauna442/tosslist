# Code of Conduct

Tosslist is a small household project shared in public. Anyone who opens an
issue, comments, or sends a change is welcome, and is asked to:

- **Be kind and patient.** Many people here are learning, including the
  maintainer.
- **Be respectful when you disagree.** Disagree with ideas, never with the
  person.
- **Be considerate.** No harassment, insults, discriminatory language, or
  posting anyone's personal information.

The maintainer may edit or remove comments, and block people who don't follow
these rules. To report a problem privately, use the contact on the
maintainer's GitHub profile (@wauna442).

Adapted in spirit from the
[AetherSDR Code of Conduct](https://github.com/aethersdr/AetherSDR/blob/main/CODE_OF_CONDUCT.md).
